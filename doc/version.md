# Версия библиотеки

Библиотека собирается из исходных кодов, получаемых с `github`.

Команда для загрузки исходных кодов в каталог `external`:
```bash
git clone https://github.com/postgres/postgres.git external
```

После этого можно посмотреть список тегов:
```bash
cd external
git tag -l 'REL_*' --sort=-version:refname | head -n 10
```

Используя один из тегов можно выбрать требуемую версию библиотеки:
```bash
git checkout REL_18_6
```

Затем можно удалить все что относится к системе контроля версий и
запретить модификацию каталога с исходными кодами библиотеки.
Для защиты от модификации предлагается сохранить исходные коды
в репозиторий, используемый для пакета. Следующая команда должна
выполняться в каталоге `external`.

```bash
rm -rf .git .gitignore
```

Сохранение `external` каталога в репозиторий текущего проекта выполняется
из корневого каталога проекта:
```bash
git add external
git commit -m "PostgreSQL source code REL_18_6"
```

Если подключен удаленный репозиторий, то можно сохранить в него данные:
```bash
git push
```
